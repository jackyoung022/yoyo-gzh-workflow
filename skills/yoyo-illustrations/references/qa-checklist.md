# YOYO v2 QA Checklist

按顺序检查。身份或内容失败时，不要先追求画风。

## 1. 内容与用途

- 16:9 横版正文配图。
- 一张图只讲一个核心结构、动作、状态或隐喻。
- YOYO 的动作能直接解释核心意思，不是站在旁边。
- 画面不是 PPT、课程页、正式流程图、复杂架构或商业吉祥物海报。
- 主体约占 40%–60%，至少 35% 留白。
- 中文标注少、短、可读，没有擅自增加标题或文案。
- 风格参考图没有污染主体、道具、动作、场景、构图、布局、文字或故事。

## 2. YOYO 身份

- 约 3.2–3.5 头身，头宽约肩宽 1.35 倍，短直腿，不是修长成人或婴儿体型。
- 年轻男性；圆角矩形黑框眼镜；平和、略腼腆的表情。
- 深蓝鸭舌帽；白边深蓝帽章；“平安喜乐”四字 2×2 排列；一个小红点。
- 深蓝工装夹克；翻领、三枚前扣、两只对称带盖胸袋、白色明线。
- 深色直筒裤、深蓝低帮系带运动鞋。
- 右侧面时能看见长帽檐、单侧镜片与眼镜腿、耳朵、鼻梁和下巴轮廓。
- 编号画风没有重绘掉角色核心识别点。

身份失败时，只强化角色参考图和身份锚点，重新生成。

## 3. 原生模式

- 干净白底、深蓝主导、实色填充、近黑干净描边。
- 无渐变、阴影、纸纹、噪点、写实 UI 和手绘抖动线。
- 米色、红、橙、浅蓝用途克制，额外颜色不超过 1–2 种。

## 4. 编号画风模式

- 交付记录的编号、名称和融合强度与解析结果一致。
- `safe`：仍是白底深蓝干净矢量，只体现形状、节奏、留白和气质。
- `balanced`：YOYO 身份和深蓝锚点稳定；局部线条、笔触、材质和少量配色能看出编号风格；背景与信息密度仍克制。
- `full`：全图媒介、线条、材质和配色明显命中编号风格，同时 YOYO 仍可识别、内容不变、一图一意。
- 解析器要求参考图时，生成调用确实包含第二张编号风格图；不要求时没有强制添加。
- 风格参考图只影响渲染语言，没有带入原图内容。

## 5. 失败处理

- YOYO 只是装饰：重写动作，让他的物理动作成为结构本身。
- 身份漂移：只强化角色锚点，不同时加强画风。
- 画风过弱：只加强解析到的正向线条、形状和媒介特征。
- 画风压过身份：`full` 降级为 `balanced` 后重生成一次。
- 风格图污染内容：强化第二张图的 style-only 隔离声明。
- 太复杂：删节点，只保留一个动作和 1–4 个物件。
- 中文错误：减少标注，只保留逐字引用的短词。
- 左上角标题：明确要求左上角保持空白，不允许标题。

每轮只解决一个主要失败点。高质量结果应先让读者觉得有意思，并在约一秒内看懂核心结构。
